# 美術方向

Crownfall 的正式畫面是**像素化的暗色奇幻 3D**：低面數模型以低解析度渲染後放大，冷暗的石地由火把點亮，不死軍團在其中自己發光。戰場精緻化的場景亮度、地形層次與角色參考見 [#98](https://github.com/CarlLee1983/Crownfall/issues/98)。

畫風的出發點是 kazzkiq 分享的一段 RPG 試玩影片（<https://x.com/kazzkiq/status/2126135161452740875>）。我們只取它的渲染手法與氛圍，不取用它的任何素材。原型保存在本機分支 `prototype/pixel-style`，用 `?variant=a|b|c|d` 比較過四種做法。

## 為什麼是 D

參考影片原汁原味的做法（變體 A）在塔防裡讀不清：敵人融進地面，射程圈與路線線被像素化成鋸齒。塔防需要玩家一眼分辨三件事：敵人在哪、哪裡能蓋塔、塔打得到哪裡。D 保留 A 的冷暗色調，再加三個辨識度手法：

1. 敵人靠模型原色、頭飾與分種發光色分辨，由較暗的車道襯出來。
2. 路線線、射程圈、放置預覽與血條以全解析度疊在像素化場景之上。
3. 環境光比參考影片亮：石地是中灰而非黑色，車道與可建區要分得出來。

原型留下的缺口：塔本身仍然偏暗，正式資產必須讓塔和地面拉開明度。

## 素材來源：KayKit

模型一律採用 Kay Lousberg 的 KayKit 素材包（CC0，授權檔已讀過確認），整套同一位作者，比例與造型語言一致：

| 用途 | 素材包 | 對應 |
| --- | --- | --- |
| 敵人 | [Character Pack: Skeletons](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0) | Minion → 骷髏兵、Rogue → 食屍鬼、Warrior → 骷髏騎士、Mage → 巫妖 |
| 塔、城堡 | [Medieval Hexagon Pack](https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0) | tower_A → 弓箭塔，其餘待選 |
| 火把、石材道具 | [Dungeon Remastered](https://github.com/KayKit-Game-Assets/KayKit-Dungeon-Remastered-1.0) | torch 系列 |

弓箭塔與骷髏兵已在原型中以實際比例驗證（[model-trial.png](model-trial.png)）。KayKit 是大頭比例，比參考影片可愛，已接受。

原型找出兩個必要的調整，正式版沿用：

- **塔的色表要降飽和**：Hexagon 包的共用色表是鮮豔卡通色，整張降到原飽和度的 45%，再以同一張貼圖當自發光、強度 0.4，塔身才讀得出來。
- **敵人發光要弱**：降低自發光強度，保留模型原色和頭飾的細節。

## 遊戲框架

- **引擎**：Three.js 0.187，WebGL，瀏覽器桌面優先。
- **相機**：固定斜俯視，偏航 45°、俯角 35°、垂直 FOV 40°，可平移與縮放（`src/render/camera.ts`）。
- **像素化**：場景以 2 CSS px 為一個渲染像素，最近鄰放大，外圈加暗角。
- **畫面上的大小**：1280×800 的預設鏡頭下，骷髏兵至少 32 CSS px 高，食屍鬼、骷髏騎士和巫妖至少 40 CSS px 高。

## 視覺系統

- **造型語言**：方正、厚重、磨損的石造建築；不死軍團瘦長、尖銳。塔的輪廓由上半部決定：弓箭塔是有垛口的箭樓，弩砲塔頂上架著弩臂，法師塔是尖頂加發光水晶。
- **輪廓優先序**：敵人種類 > 塔種類 > 塔等級 > 地形細節。四種敵人靠頭飾、體型、主色和各自的發光色分辨。
- **明度結構**：高台、車道、低層苔地、峭壁面依序變暗。塔要和地面拉開明度，火把在夜景中留下暖色光區。
- **配色角色**：

  | 角色 | 色值 | 用途 |
  | --- | --- | --- |
  | 石地 | 去飽和冷灰，飽和度約原色 35% | 車道、高台、峭壁 |
  | 苔地 | 暗橄欖綠 | 低層可建區 |
  | 火光 | `#ff9a3c`／火焰 `#ffb347` | 火把、入口、城堡 |
  | 不死發光 | 骷髏兵金黃、食屍鬼綠、骷髏騎士藍、巫妖紫紅 | 敵人本體 |
  | 塔強調色 | 弓箭塔木棕、弩砲塔鐵灰帶銅、法師塔紫晶 | 只用在塔頂，不鋪滿整座 |
  | 覆蓋物 | 路線 `#1e6e78`、射程圈米白 | 全解析度層 |

- **材質**：平塗色塊加小尺寸像素貼圖（石磚、木紋），不用 PBR 細節貼圖；光照交給場景燈光，不烘進貼圖。
- **燈光**：偏藍的側向月光＋半球環境光＋閃爍的火把點光源。火把放在入口、城堡和高台邊緣。
- **氛圍**：指數霧（暗綠）、暗角。雨等天氣效果之後再議，不能降低辨識度。
- **動態**：敵人播 `Walking_A` 行走。被擊殺時以 2 倍速播 `Death_C_Skeletons` 散架，再下沉。受擊以閃白與輕微後仰回饋，不疊加 `Hit_A`。
- **不要**：寫實 PBR、高頻雜訊貼圖（像素化後變成閃爍）、細線條裝飾、和敵人發光色撞色的塔。

## 技術合約

- **格式**：每個資產一個 GLB（glTF 2.0），放在 `src/render/models/`，以 `import url from './<id>.glb?url'` 引用，讓 Vite 產生帶雜湊的檔名；檔名用 manifest 的 `id`。
- **前處理**：一支腳本以 `@gltf-transform` 從 KayKit 原檔產出 GLB——只留用到的動畫、把武器綁進手部骨骼、把塔的色表降飽和烘進貼圖。輸出檔進 repo，原檔不進；manifest 記錄來源 repo 與 commit SHA。
- **單位與軸**：1 世界單位 = 1 格；Y 軸朝上；一個高度層 = 0.6 單位（`LAYER_HEIGHT`）。
- **原點**：底面中心，模型站在 y = 0 上。Hexagon 塔縮放 ×0.7。骷髏兵、食屍鬼和骷髏騎士縮放 ×0.39，巫妖 ×0.5。
- **面朝向**：敵人正面朝 +Z（前進方向由程式轉向）。
- **代理底面尺寸**：沿用現有幾何體的佔地，這些尺寸影響轉彎與地形支撐的視覺一致性。

  | 物件 | 底面 | 高度參考 |
  | --- | --- | --- |
  | 弓箭塔 | 0.8 × 0.8 | 0.75 |
  | 弩砲塔 | 直徑 0.8 | 1.18 |
  | 法師塔 | 直徑 0.88 | 0.68（可加高，但塔頂升級標記會跟著移） |
  | 骷髏兵 | 0.5 | 約 0.5 |
  | 食屍鬼 | 0.4 | 約 0.4 |
  | 骷髏騎士 | 0.8，切角 0.1 | 約 0.8 |
  | 巫妖 | 直徑 1.0（圓形底面，過彎需要） | 約 1.0 |

- **預算**：敵人約 5,300 三角面、塔約 2,100（KayKit 原始值，像素化後細節多餘但不構成負擔）；貼圖共用素材包的 1024×1024 色表、最近鄰取樣、sRGB。
- **檔案大小**：Skeletons 每個 GLB 約 4.8MB，大半是 95 段動畫；正式版只保留用到的動畫再輸出。
- **授權**：只用 CC0 或自製；每個檔案在 [asset-manifest.json](asset-manifest.json) 登記來源與授權。

## 實作決定

架構上的取捨見 [ADR 0003](../adr/0003-pixelated-scene-crisp-overlays.md)：場景像素化、資訊覆蓋層全解析度，模型掛在隱形代理之下。其餘決定：

- **切分**：三個 PR，每個都能單獨上線。(1) 像素化管線、冷暗配色、火把光、覆蓋層，模型仍是方塊；(2) 載入管線＋弓箭塔與骷髏兵；(3) 其餘塔、敵人與入口、城堡、火把道具。三者都排在 v0.1.0 發版之前。
- **像素大小**：以 CSS 像素計，一個渲染像素 = 2 CSS px，不隨 DPR 改變。
- **載入**：標題畫面預載全部模型，載完才能按「開始遊戲」；失敗就顯示錯誤，不退回方塊。
- **塔的 picking 尺寸**：載入時從模型包圍盒算出。
- **塔**：弓箭塔 `tower_A`；弩砲塔 `tower_B` 頂上加放大的 `Crossbow`；法師塔 `church` 尖頂加程式生成的發光水晶。升級沿用塔頂金色標記。
- **敵人**：行走動畫速度跟著移動速度。受擊用閃白與後仰，死亡散架期間隱藏血條。骷髏騎士拿劍與大盾、食屍鬼拿雙刀、巫妖拿法杖、骷髏兵空手。
- **地形**：維持程式生成的方塊，加石磚與苔地像素貼圖。入口用 `wall_straight_gate`，城堡用 `building_castle`，漏怪時城堡模型自發光閃紅。
- **火把與光**：位置寫在只給 render 讀的 `src/content/decor.ts`，至多 8 支，使用 `torch_mounted`；不開陰影貼圖。
- **smoke test**：改以「入口區有明顯比地面亮的像素」判斷敵人出現。
- **署名**：README 與 itch.io 頁面加「3D 模型：KayKit by Kay Lousberg (CC0)」，遊戲畫面不放。
